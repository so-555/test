# 自己紹介サイト＋ミニゲーム

シンプルな自己紹介ページと、反射神経を試す30秒チャレンジゲームを含む静的サイトです。`index.html`をブラウザで開き、ヘッダのリンクからゲームページへ移動できます。

- `index.html` – プロフィールや興味関心をまとめた自己紹介ページ
- `game.html` – ターゲットをクリックしてスコアを稼ぐ集中力ゲーム
- `assets/styles.css` – 両ページ共通のスタイル
- `assets/game.js` – ゲームのロジック

ローカルで確認する場合は、任意の静的サーバーかブラウザで直接HTMLファイルを開いてください。
